# Asset attribution

## Original profile artwork

`profile-banner.svg`, `typing-headline.svg`, `divider.svg`, `footer.svg`, and the local call-to-action badges are original SVG artwork created for this profile. The visual layout is inspired by [StephenSook's GitHub profile](https://github.com/StephenSook); no assets or source were copied from that profile.

## Technology icons

The eight technology marks in `assets/icons/` are vendored from [Devicon](https://github.com/devicons/devicon/tree/7330accdbc47e2dc0c19789a48533c4a3c50fe58) at commit `7330accdbc47e2dc0c19789a48533c4a3c50fe58` and distributed under Devicon's MIT license, reproduced below.

Each SVG retains the upstream icon paths and colors. The local adaptation adds a 40 × 40 canvas, accessible title, and a pale neutral rounded tile with a border so the marks remain visible in both GitHub themes. Icons are scaled to 28 × 28 within that tile. No remote fonts, images, scripts, or other external resources are embedded.
